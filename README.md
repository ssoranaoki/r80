# R80 練習帳

考えを **2文・80字以内** でパッと書くための練習アプリです。

## R80 とは

茨城県の元校長・中島博司さんが考えた、短く論理的に書くための文章術です。ルールは2つだけです。

1. 2文で、合わせて80字以内に書く（1文あたり約40字）
2. 2文目は必ず接続詞（「なぜなら」「しかし」「だから」など）から始める

1文目に結論、2文目に理由や根拠を書くことで、筋道の通った文章を書く癖がつきます。

## 使い方

ブラウザで `index.html` を開くだけで使えます。インストールは要りません。

- 原稿用紙のマス目に書く（1文＝20マス×2行。半角の英数字は全角になります）
- 字数と、ルールを守れているかがその場でわかる
- 接続詞を種類別の一覧から選んで、2文目の先頭に入れられる
- 「残す」で履歴に保存し、同時にクリップボードへコピー（新しい順に表示。1本ずつコピー・削除できる）
- 2分タイマー
- キーボードだけで操作できる（`Enter` で次の欄、`Alt`+`J` で接続詞、`Alt`+`S` で残す、`Alt`+`R` で書き直す、`Alt`+`T` でタイマー）

書いた文章はお使いのブラウザの中（localStorage）にだけ保存され、外部には送られません。

## 接続詞のデータ

接続詞の一覧は、開いたときに [Wiktionary 日本語版](https://ja.wiktionary.org/) の「日本語 接続詞」カテゴリから取得しています。インターネットにつながっていないと一覧は表示されません。
